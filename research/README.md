# Reconstructed Terraria research texts

The source checkpoint includes independently written loader and analysis tools. Separate ZIP downloads contain sanitized text reconstructions from the analyzed Android build: decompiler C candidates, native-range candidates, declaration outlines and Java decompilation. Alternative profiles remain separate.

These are not the original C# project, not a buildable game and not proof of semantic equivalence. Failed or incomplete recovery remains explicit. A recovered candidate is not a verified implementation.

APK/DEX/ELF binaries, Unity resources, signing keys, saves, Ghidra databases, screenshots and raw device logs are excluded. Private paths and identifiers are removed; excluded wrapper references are anonymized. Tools with anonymized paths require local configuration.

Terraria and its original code remain the property of their respective rights holders. This project grants no rights to third-party material and is not affiliated with Re-Logic or the tModLoader team. The experimental loader does not run arbitrary PC mods.

Downloads and hashes are listed in `manifest.json` after packaging. Primary project documentation is English.
