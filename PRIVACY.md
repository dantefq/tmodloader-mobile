# Publication scope and privacy

This repository starts from a new, sanitized root commit. Earlier development history and older release attachments are not part of this repository. They were not made public with this publication.

The source tree and every member of the research downloads are checked for personal filesystem paths, known private identifiers, device model/serial references and credential patterns. Binaries, assets, saves, screenshots, raw device logs and private queue journals are excluded. Text reconstructions have privacy substitutions; hashes refer to the published, sanitized bytes.

The source snapshot is additionally checked through Python/JavaScript syntax checks, the managed host suite and selected orchestration/ownership tests. These checks do not establish Android runtime stability or full mod compatibility.

GitHub necessarily displays the repository owner's account and platform-generated publication metadata. These are separate from the sanitized project content.

No guarantee is made about copies previously downloaded from other repositories, platform caches or private local workspaces. This publication does not expose the earlier development repository or its history.
