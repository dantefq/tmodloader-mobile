# tModLoader Mobile — Experimental

Русский · [English](README.md)

Экспериментальный проект для выполнения отдельных ПК-модов Terraria внутри Android-версии игры через самостоятельно написанный слой совместимости и нативные адаптеры.

**Состояние на 20.10.2026: исходники прототипа, а не универсальный мобильный tModLoader или готовый установщик.**

## Что уже продемонстрировано

- Изменения предметов через JSON и собственные ПК-моды GlobalItem/ModItem внутри мобильной игры.
- Тестовый предмет с отдельным runtime ID, подсказкой и настоящими атаками; сохранение через sidecar и автоматическое восстановление после нового запуска процесса игры.
- Исходная неизменённая DLL ChangeSleepTime на Android, настоящий сон, настройка ускорения времени, выключение/включение и сохранение/перезапуск.
- Общая сборка item/time: единый Mono, реальные атаки и сон, восстановление сохранённого предмета после перезапуска. Цикл off/on именно общей сборки ещё не проверен.
- Бессмертие и отсутствие отбрасывания лабораторного персонажа, включая контролируемые удары и переключение защиты.
- Исходные callbacks ShorterRespawn в изолированной среде и отдельный нативный адаптер настоящего возрождения. Наблюдались короткий, выключенный и длинный таймеры; итоговая проверка сохранения/перезапуска не завершена.

Проверки относятся к ограниченным сценариям и не доказывают совместимость с произвольными ПК-модами.

## Ограничения

[Android-адаптер текстур](tools/ANDROID_TEXTURE_BRIDGE.ru.md) запускает собственный C#-реестр и временную native-иконку внутри одного игрового процесса через отдельный тестовый companion; ACK выгрузки следует за настоящей очисткой. Используется фиксированная собственная текстура; общий загрузчик и инвентарь/gameplay ещё нужны.

- **Импорт произвольных `.tmod`, полный API tModLoader, multiplayer, Calamity, Infernum Mode и Thorium не поддерживаются.**
- **Secrets Of The Shadows** выбран следующим контентным модом. Исходные настройки `HelicopterParts`, `Snakeskin` и `Curgeon` выполнены на host-снимках и совпали с вложенными исходниками; три текстуры декодированы на CPU. Для одной исходной текстуры также прошёл лабораторный путь от живого host-реестра до native-иконки с проверками поколения и очистки. Полный lifecycle мода и gameplay не проверены.
- Цель текущего прототипа — native ARM64 и одна исследованная сборка Android-игры. Другие версии, подписи и архитектуры требуют отдельной работы. Исследованный маршрут эмулятора с ARM-трансляцией не дошёл до выполнения managed-модов.
- Для каждого нового процесса игры пока нужны компьютер и разрешённый USB/ADB bootstrap. Самостоятельный запуск не завершён. Часть диагностики и лабораторных команд требует root; это не относится ко всем проверенным маршрутам.
- Для companion instrumentation нужен совместимый сертификат подписи. Произвольная официальная установка автоматически не поддерживается. APK игры и ключей подписи здесь нет.
- Respawn использует отдельные snapshot API и сборку; в общий item/time он ещё не включён. Разные варианты сборок имеют разный проверенный набор функций.
- Сохранения поддерживают один известный предмет в заданном инвентаре/профиле/мире. Запись player и sidecar не атомарна; несовпадение отклоняется, общего восстановления и миграции нет. Банки, сундуки и данные мира ещё не реализованы.
- Настоящие projectile/NPC, тайлы и генерация мира, ресурсы/отрисовка, рецепты, UI и произвольные On/IL hooks требуют существенной работы. Широкая совместимость, длительная стабильность и производительность не доказаны.

Достоверной даты релиза и осмысленного процента совместимости нет.

## Разработка и запуск

В репозитории находятся наши исходники Java, C#, JavaScript и Python. Игровые файлы, сторонние модовые DLL, сохранения, подробные отчёты об устройствах, ключи и результаты сборок не публикуются.

Инструменты используют Python, Node.js, .NET SDK, JDK, Android SDK, закреплённый Mono runtime и Frida Gadget. Параметры отдельных скриптов доступны через `--help`. Части проверок нужны локальные зависимости и закрытые отчёты предыдущих этапов; свежий clone не является автономным окружением сборки.

Для уже собранного совместимого companion сначала сохранить мир и выйти:

```powershell
python tools/start_mobile.py --serial <ADB_SERIAL> --managed-demo --saved-and-exited
```

Команда не устанавливает зависимости и не преобразует произвольные `.tmod`. Предварительно нужен подходящий вариант companion. Сборщики не устанавливают результат автоматически. Перед экспериментами сохранять резервные копии игровых файлов и sidecar; очистка данных приложения не является способом обновления.

Поддерживаемые функции выключаются через **Mobile Mods**, затем при необходимости нужны сохранение/выход и повторная загрузка. Для обычной игры запускать оригинал штатно; sidecar и копии сохранять до безопасного восстановления модового контента.

## Авторы и права

Разработка ведётся с OpenAI Codex и помощью AI. Terraria принадлежит правообладателям. tModLoader и сторонние моды принадлежат своим авторам и здесь не распространяются. Лицензии и notices Frida и Mono/.NET сохраняются: [Frida](https://github.com/frida/frida), [dotnet/runtime](https://github.com/dotnet/runtime), [tModLoader](https://github.com/tModLoader/tModLoader).

Общая open-source лицензия проекта пока не объявлена. Публичный доступ сам по себе не предоставляет права на распространение. Это независимый проект, не официальный продукт Terraria или tModLoader.

## Последняя проверка

Внутрипроцессная проба выполнила отрисовку и очистку, затем игра завершилась с native-ошибкой потоков/сигналов. Кандидат с запуском Mono до Unity собран, но ещё не проверен на Android. Стабильность не подтверждена. Основное описание проекта — английское; материалы реверса описаны в [research/README.md](research/README.md).
