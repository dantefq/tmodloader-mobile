# Проверка зависимостей контента

[English](CONTENT_REACHABILITY.md)

`audit_content_reachability.py` проверяет payload локального `.tmod` и зависимости IL конкретного типа, не загружая DLL в CLR для выполнения. Собственный анализатор собирается закреплённым .NET SDK. DLL, результаты компиляции и отчёты сохраняются вне исходников проекта.

```powershell
python tools/audit_content_reachability.py '<mod.tmod>' --assembly SOTS.dll --type SOTS.Items.AbandonedVillage.AVPot --lab '<private-lab>'
python tools/test_content_reachability.py
```

Анализ учитывает локальные вызовы, унаследованные локальные методы, конструкторы и статические инициализаторы владельцев ссылок. `--methods .ctor SetDefaults` ограничивает корневые методы, сохраняя транзитивные вызовы и инициализаторы. Module initializer включается и помечается явно. Сохраняются token вызывающего метода, смещение IL, opcode, token цели и сигнатура. Для generic-вызовов дополнительно сохраняются исходный token и blob специализации. Перегрузки различаются по token. Имена generic-владельцев и сигнатуры методов/полей декодируются в читаемый вид.

Внешние зависимости, отсутствующие тела, виртуальные и косвенные вызовы отмечаются явно. `callvirt` консервативно помечается и при использовании только для проверки null. Читаемое имя generic-владельца не разрешает его методы и правила инициализации. Reflection, делегаты, внешний жизненный цикл и зависимости типов из сигнатур/локальных переменных требуют дальнейшей проверки. Это инвентаризация, а не полный семантический граф и не разрешение запуска. `safe_to_execute`, `assembly_executed`, `compatibility_verified` всегда false.

Регрессионные проверки собирают собственный пример: проверяются наследование, вспомогательные методы и статические инициализаторы, перегрузки, исключение посторонних методов, неопределённость dispatch и отказ при отсутствующем типе/повреждённом файле. Работа мода на Android этим не проверяется.

Первый аудит закреплён на SOTS 0.25.1.9; хеши приведены в английской версии. AVPot требует API тайлов; AncientSteelBar, OldKey и ExcavatorMask обращаются к графическим ресурсам через вспомогательный код. Код SOTS не исполнялся. Оригинальный код, ресурсы и подробные отчёты остаются приватными; разрешение на распространение не предполагается.

Последующие отдельные пробы исполнения исходного кода описаны в [host-пробе](SOTS_HOST_SLICE.ru.md).
