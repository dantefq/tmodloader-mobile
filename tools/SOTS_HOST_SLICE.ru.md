# Исходный SOTS: ограниченная host-проба

[English](SOTS_HOST_SLICE.md)

Версия и хеши SOTS закреплены в [AGENTS.md](../AGENTS.md). Исходные файлы мода, ресурсы и подробные результаты остаются в приватной лаборатории; разрешение на распространение не предполагается.

```powershell
python tools/probe_sots_item_defaults.py '<SOTS.tmod>' --lab '<private-lab>'
python tools/probe_sots_item_defaults.py '<SOTS.tmod>' --lab '<private-lab>' --type SOTS.Items.Pyramid.Snakeskin
python tools/probe_sots_item_defaults.py '<SOTS.tmod>' --lab '<private-lab>' --type SOTS.Items.Fishing.Curgeon
python tools/test_pc_item_economy.py --lab '<private-lab>'
python tools/test_sots_probe_scope.py
```

Первая команда **исполняет оригинальный код мода** в отдельном host CLR-процессе. До запуска проверяются хеши архива/DLL/исходника и IL-пути выбранных конструктора/SetDefaults. Должны совпасть методы, количества зависимостей и сигнатуры. Неожиданные инициализаторы, непрямые вызовы, изменения сигнатур и generic-специализации отвергаются. Это профиль одного закреплённого предмета, а не универсальная песочница для чужих DLL.

Оригинальные конструктор и SetDefaults выбранного HelicopterParts, Snakeskin или Curgeon вызываются с собственным API снимков предметов. Два экземпляра сверяются с данными, извлечёнными из вложенного исходника; символ редкости разрешается через таблицу констант локального ПК-API. DLL мода не переписывается и не перекомпилируется. Mod.Load, SetStaticDefaults, регистрация, рецепты, эффекты, сохранения и Android не вызываются и не проверяются.

Поля width/height теперь принадлежат Entity. buyPrice/sellPrice сохраняют Int32-арифметику с переполнением. Собственная проба, собранная против ПК-tModLoader, проверяет связывание членов и выбранные значения при запуске с нашим API. Сам ПК-клиент этим не запускается.

Текстура читается через MobileTmodArchive и MobileRawImage: три little-endian Int32 (версия/ширина/высота), затем RGBA. Формат сверен с официальным ImageIO; ссылки есть в английской версии. Проверяются размеры, точная длина и бюджет до распаковки ресурса. Пиксели не преобразуются. Более строгий отказ при повреждённых данных намеренный. Текстура в GPU не создаётся.

Для трёх типов наблюдалось совпадение по двум экземплярам (всего шесть снимков) с вложенными исходниками, размеров текстур с предметами и хешей декодированных пикселей с payload. PNG-представления дополнительно проверены независимым декодером Pillow: три исходные текстуры и три примера прозрачности/порядка строк. Android, отрисовка и полный SOTS не проверены.

Последующие отдельные [native-пробы текстур](DEVICE_TEXTURE_PROBE.ru.md) подтвердили временную Unity-загрузку/чтение и мобильную XNA-обёртку HelicopterParts на ARM64. Доставка пакета, отдельный Asset и откат отдельного массива также проверены; краткое превью меню просмотрено, затем удалено. DLL SOTS этим не исполняется, инвентарный предмет не регистрируется.

`MobileContentRegistry.ReadItemImage` разрешает rawimg-путь зарегистрированного предмета через загруженного поставщика ресурсов и LRU-кэш реестра. Ванильные ссылки на атлас явно требуют native-моста. Ключ включает SHA-256 архива и нормализованный путь; выгрузка очищает владение кэшем. Настраиваемый бюджет ограничивает пиксельные байты внутри кэша, а не весь процесс, временные выделения декодера/PNG или изображения, удерживаемые вызывающим кодом. Пройдены 17 синтетических проверок реестра/ресурсов/lifecycle (включая другого поставщика и ошибку выгрузки) и 27 проверок изображений/кэша/границ. Проверки lifecycle реестра используют собственные примеры, а не полный lifecycle SOTS.

Последующая [текстурная проба собственного реестра](ITEM_TEXTURE_BINDING.ru.md) удерживает владельца C# до native ItemSlot-иконки и очистки таблиц/ресурсов. Закреплённая текстура скопирована в явно отдельный приватный лабораторный архив; исходный код SOTS не исполняется. Настоящие manifest, зависимости и полный lifecycle SOTS этим не реализованы.
