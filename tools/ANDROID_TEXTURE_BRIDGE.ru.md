# Лабораторный адаптер текстур Android

[English](ANDROID_TEXTURE_BRIDGE.md) · [Проба иконки](ITEM_TEXTURE_BINDING.ru.md)

`MobileTextureBridge` выдаёт одну ожидающую передачу текстуры предмета из существующего реестра. Конверт содержит план передачи и пакет TMIT в Base64; предел — 94 208 символов. Backend сохраняет ограниченное подмножество PNG: сторона до 256, данные до 64 КиБ. Если экспорт не вернулся вызывающему коду, отказ освобождает ещё не опубликованную передачу: слишком длинное имя предмета не оставляет выгрузку заблокированной. Все пользователи реестра должны сериализовать операции через один переданный gate.

`BeginItem` возвращает конверт, `ReadExport` повторно проверяет владельца, `CompleteNativeTeardown` требует соответствующий канонический ID передачи. `Unload` сохраняет барьер ожидающей передачи. ID связывает запрос и ответ, но не аутентифицирует отправителя и не доказывает завершение GPU-работы. JavaScript-ридер требует отдельно заданные поколение/предмет, отклоняет неканонический Base64 и передаёт пакет ограниченному TMIT-ридеру. Managed-код проверяет распакованные строки PNG до экспорта.

Проведены три разные Android-проверки:

- **Отдельное приложение:** собственный C#-реестр и изображение RGBA 2×2, передача managed → JavaScript, отказы выгрузки/ACK, GC и последующая выгрузка. Подтверждения GPU-очистки здесь имитируются, поскольку игровая графика не создаётся.
- **Игровая проба в двух процессах:** реестр остаётся активным в собственном Android-приложении, а внешний контроллер передаёт проверенный конверт в лабораторный native-адаптер иконки Terraria. После GC экспорт остаётся прежним. Адаптер проверяет четыре RGBA-образца, включая прозрачность, отклоняет шесть неверных входов, публикует/восстанавливает 129 копий таблиц и наблюдает удаление ресурсов. Только затем контроллер возвращает соответствующий ACK на Android и выгружает реестр. Здесь подтверждение следует за настоящей native-очисткой.
- **Тестовый companion внутри процесса:** отдельный подписанный instrumentation-пакет загружает точно проверенные на Android собственные сборки и Mono в игровой процесс, используя свою лабораторную папку. Там прошли те же 29 managed-проверок, GC и последовательность native-иконка/откат/удаление/ACK. APK игры сохранился; после отключения контроллеров прошли проверки процесса, четырёх сохранений и crash-буфера. Сцена — главное меню, предмет в инвентарь не добавлялся.

Оба игровых пути прошли с итоговым ограниченным адаптером. Проба в двух процессах сохраняет уже работающий игровой процесс. Запуск instrumentation для общего процесса намеренно перезапускает игру после сверки актуальной резервной копии; новый процесс пережил пробу и отключение контроллеров. Эти лабораторные проверки не подтверждают инвентарь/gameplay, импорт произвольных модов и запуск исходной DLL мода. Снимки игры остаются приватными; отдельное визуальное совпадение крошечного собственного изображения не заявляется.

Наборы исходников содержат 29 случаев экспорта/lifecycle адаптера и 18 JavaScript-случаев конверта. Те же 29 managed-проверок выполняются при инициализации Android-пробы. Они включают отказ слишком большого экспорта без зависшей передачи. Полный managed host-набор прошёл; внешние upstream conformance inputs не задавались. Прежний host/native-путь закреплённой исходной иконки также прошёл после подключения общего адаптера.

Сборка и запуск в новых приватных папках, с существующим закреплённым пакетом Mono и уже настроенным loopback Frida:

```powershell
python tools/build_texture_bridge_probe.py --sdk '<SDK>' --jdk '<JDK>' --lab '<new-private-build>' --key '<private-key>' --cert '<certificate>'
python tools/probe_android_texture_bridge.py --serial '<serial>' --build '<private-build>' --lab '<new-private-evidence>'
python tools/probe_android_texture_bridge.py --serial '<serial>' --build '<private-build>' --lab '<another-new-private-evidence>' --native-game --save-backup '<private-Players-Worlds.tar>'
node tools/test_texture_export.js
```

Сборщик ничего не устанавливает и не перезаписывает прежние отчёты. Runner устанавливает/запускает только собственное приложение пробы. Native-game дополнительно требует уже работающую игру и актуальную приватную копию сохранений; существующий процесс возвращается на передний план, native-адаптер проверяет главный поток и offline-меню. Сборки, runtime-библиотеки и подробные доказательства остаются вне публикуемых исходников.

Неопределённая native-очистка не разрешает ACK. Контроллер сохраняет состояние восстановления и по возможности удерживает Android-контроллер. Удержание при паузе/ошибке покрыто host-имитациями, но не намеренным сбоем на устройстве. Незавершённое восстановление нужно разрешить до следующей пробы.

Отдельный companion требует исследованную установку с сертификатом разработки и совпадающую подпись. Он собирается только из точно проверенной собственной Android-пробы:

```powershell
python tools/build_texture_companion.py --sdk '<SDK>' --jdk '<JDK>' --lab '<new-private-companion-build>' --key '<private-key>' --cert '<certificate>' --source '<pinned-target.apk>' --probe-build '<passed-private-probe-build>' --probe-validation '<passed-two-process-evidence>/validation.json'
python tools/start_texture_companion.py --serial '<serial>' --build '<companion-build>' --probe-build '<probe-build>' --lab '<new-private-preparation>' --save-backup '<private-Players-Worlds.tar>' --saved-and-exited
python tools/probe_texture_companion.py --prepared '<preparation>/prepared.json' --lab '<new-private-in-process-evidence>'
```

Подготовка загружает библиотеки и сверяет скопированные сборки; это ещё не успешная графическая проверка. Перед пробой нужно проверить главное меню. Тестовый вариант не меняет существующий item/time companion, его настройки и sidecar. В нём нет Gadget и общего импортера; авторизованный внешний ADB/Frida-контроллер пока нужен. После испытаний для обычной игры запускать игру штатно.

Ещё нужны общая item/time-сборка и пользовательское управление, динамические ID, несколько владельцев контента, инвентарь/defaults/подсказки/gameplay, сохранения, исходный lifecycle SOTS и длительные проверки ресурсов.

## Уточнение lifecycle — 2026-10-20

Новая проба исходной текстуры прошла отрисовку, откат таблиц, удаление ресурсов и ACK внутри игры, но после отключения контроллера процесс завершился с native-ошибкой Mono. Новый порядок инициализации Mono до Unity пока только собран; Android и post-detach проверки ещё не выполнялись. Краткие прежние проверки не подтверждают стабильность.
