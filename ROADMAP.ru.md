# План

[English](ROADMAP.md) · [README](README.ru.md)

Конечная исследовательская цель — **Calamity + Infernum Mode на Android**. Реализуемость и сроки не установлены. SOTS — следующий выбранный контентный мод.

1. Закончить ShorterRespawn: сохранённая матрица on/off/long/live adjustment, новый процесс и безопасное финальное состояние.
2. Укрепить общий item/time: off/save/reload/on той же сборки и настоящий сон после restart.
3. Первый элемент SOTS: lifecycle/достижимые вызовы, неизменённая DLL в отдельном Android probe, затем один настоящий предмет с исходной текстурой, поведением, save/restart и отключением.
4. Обобщить lifecycle/config/registry/зависимости и стабильные ID для нескольких модов; явно отклонять неподдерживаемые пути.
5. Восстановимые сохранения: согласованный экспорт/restore player/sidecar, миграция, сохранение записей отсутствующего мода и другие инвентари.
6. Подключить реальные projectile/NPC, ресурсы/отрисовку, рецепты, тайлы/данные/генерацию мира; проверять в игре перед расширением SOTS.
7. Разрешить блокеры Calamity/Infernum по API, зависимостям, hooks, rendering и worldgen; совместно проверить бой, save и производительность.
8. Поддерживаемый самостоятельный install/launch/update/recovery и расширение платформ. Multiplayer — отдельный поздний этап.

Другие небольшие моды и Thorium остаются возможными будущими целями. Один успешный элемент не означает поддержку всего мода. План пересматривать по lifecycle/контенту/save/производительности; число тестов не измеряет готовность.
