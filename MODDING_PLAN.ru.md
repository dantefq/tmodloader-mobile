# Архитектура

[English](MODDING_PLAN.md) · [README](README.ru.md)

Android Terraria использует Unity/IL2CPP, ПК-моды tModLoader — managed-сборки. Прототип исполняет выбранный код через Mono и переносит узкие поддерживаемые взаимодействия в мобильный runtime.

| Компонент | Задача |
|---|---|
| Java companion/instrumentation | Валидация фиксированного bundle, подготовка runtime, USB/ADB-запуск с совместимым сертификатом |
| Frida/native bridge | Проверенная IL2CPP metadata, привязки методов/полей конкретной сборки и guards |
| Общий Mono bootstrap | Domain/image, подключение потоков, сбалансированные GC-переходы и rooting значений |
| Независимый API совместимости | Выбранные контракты config, metadata, registry, item/time и сохранений |
| Адаптеры функций | Реальное состояние игры; respawn имеет отдельный ограниченный snapshot host и scoped clamp lease |
| Sidecar | Стабильный ключ предмета/hash player и vanilla placeholder; отказ при mismatch без атомарного восстановления |

Сборщики проверяют закреплённые входы и предыдущие изолированные checkpoints, затем создают закрытые артефакты. Варианты имеют разный проверенный объём; установка одного не объединяет все функции.

Managed-снимки — значения, не нативные игровые объекты. Широкому контенту нужны lifecycle, исходные ресурсы, native bindings, зависимости и семантика мира/save. Произвольные desktop On/IL hooks нельзя считать работающими на IL2CPP.

Игровые assemblies, декомпилированный код игры, сторонние DLL, закрытые доказательства и ключи не распространяются. См. [ограничения](README.ru.md#ограничения) и [план](ROADMAP.ru.md).
